Operaciones con fracciones: Suma y resta

La suma y resta de fracciones son operaciones fundamentales que requieren encontrar un denominador común. Estas operaciones son la base para resolver problemas más complejos con fracciones.

Para sumar fracciones, necesitamos que tengan el mismo denominador. Existen dos casos principales:

Caso 1: Mismo denominador

Si las fracciones tienen el mismo denominador, se suman los numeradores y se mantiene el denominador

a/b + c/b = (a + c)/b
Ejemplo:
2/5 + 3/5 = (2 + 3)/5 = 5/5 = 1
Caso 2: Denominadores diferentes

Se busca el MCM de los denominadores y se convierten las fracciones a equivalentes con ese denominador

a/b + c/d = (a × k + c × m)/mkt(b,d)
Ejemplo:
1/3 + 1/4 = 4/12 + 3/12 = 7/12

Ejemplo resuelto: 2/3 + 1/6

Paso a paso:

1. MCM(3, 6) = 6
2. 2/3 = (2 × 2)/(3 × 2) = 4/6
3. 1/6 ya tiene denominador 6
4. 4/6 + 1/6 = 5/6

Por tanto, 2/3 + 1/6 = 5/6

La resta de fracciones sigue el mismo principio que la suma, pero restando los numeradores:

Caso 1: Mismo denominador
a/b - c/b = (a - c)/b
Ejemplo:
7/8 - 3/8 = (7 - 3)/8 = 4/8 = 1/2
Caso 2: Denominadores diferentes
a/b - c/d = (a × k - c × m)/mkt(b,d)
Ejemplo:
3/4 - 1/6 = 9/12 - 2/12 = 7/12

Ejemplo resuelto: 5/6 - 1/4

Paso a paso:

1. MCM(6, 4) = 12
2. 5/6 = (5 × 2)/(6 × 2) = 10/12
3. 1/4 = (1 × 3)/(4 × 3) = 3/12
4. 10/12 - 3/12 = 7/12

Por tanto, 5/6 - 1/4 = 7/12

Cuando tenemos sumas y restas combinadas, seguimos el orden de prioridad (de izquierda a derecha) y simplificamos paso a paso:

Ejemplo: 2/3 + 1/4 - 1/6

Paso a paso:

1. MCM(3, 4, 6) = 12
2. 2/3 = 8/12, 1/4 = 3/12, 1/6 = 2/12
3. 8/12 + 3/12 = 11/12
4. 11/12 - 2/12 = 9/12
5. Simplificar: 9/12 = 3/4

Por tanto, 2/3 + 1/4 - 1/6 = 3/4
