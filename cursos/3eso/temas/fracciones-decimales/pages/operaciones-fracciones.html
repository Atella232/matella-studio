Operaciones con Fracciones

Suma y Resta de Fracciones

Cuando las fracciones tienen el mismo denominador, se suman o restan los numeradores y se mantiene el denominador común.

\\[ \frac{a}{c} + \frac{b}{c} = \frac{a+b}{c} \\quad | \\quad \frac{a}{c} - \frac{b}{c} = \frac{a-b}{c} \\]

Ejemplo: \\(\\frac{2}{7} + \\frac{3}{7} = \\frac{2+3}{7} = \\frac{5}{7}\\)

Cuando las fracciones tienen distinto denominador, primero hay que encontrar el mínimo común múltiplo (mcm) de los denominadores para obtener un denominador común.

Pasos a seguir:

  1. Calcular el mcm de los denominadores
  2. Convertir cada fracción a denominador común
  3. Sumar o restar los numeradores
  4. Simplificar el resultado

Ejemplo: \\(\\frac{1}{4} + \\frac{1}{6}\\)

Paso 1: mcm(4, 6) = 12

Paso 2: Convertir: \\(\\frac{1}{4} = \\frac{3}{12}\\) y \\(\\frac{1}{6} = \\frac{2}{12}\\)

Paso 3: Sumar: \\(\\frac{3}{12} + \\frac{2}{12} = \\frac{5}{12}\\)

Resultado: \\(\\frac{1}{4} + \\frac{1}{6} = \\frac{5}{12}\\)

Multiplicación de Fracciones

Para multiplicar fracciones, se multiplican los numeradores entre sí y los denominadores entre sí.

Regla de multiplicación

\\[ \frac{a}{b} \\times \frac{c}{d} = \\frac{a \\times c}{b \\times d} \\quad \\text{con } b \\neq 0 \\text{ y } d \\neq 0 \\]

Ejemplo 1: Fracciones simples

Calcular: \\(\\frac{2}{3} \\times \\frac{4}{5}\\)

\\( \\frac{2}{3} \\times \\frac{4}{5} = \\frac{2 \\times 4}{3 \\times 5} = \\frac{8}{15} \\)

Resultado: \\(\\frac{8}{15}\\)

Ejemplo 2: Simplificación previa

Calcular: \\(\\frac{4}{9} \\times \\frac{3}{8}\\)

Método 1: Sin simplificar primero (no recomendable)

\\( \\frac{4}{9} \\times \\frac{3}{8} = \\frac{4 \\times 3}{9 \\times 8} = \\frac{12}{72} = \\frac{1}{6} \\)

Método 2: Simplificando antes de multiplicar (recomendable)

Observamos que 4 y 8 tienen MCD=4, y 3 y 9 tienen MCD=3

\\[ \\frac{4}{9} \\times \\frac{3}{8} = \\frac{\\cancel{4}}{9} \\times \\frac{3}{\\cancel{8}} = \\frac{1}{9} \\times \\frac{3}{2} = \\frac{1 \\times 3}{9 \\times 2} = \\frac{3}{18} = \\frac{1}{6} \\]

Resultado final: \\(\\frac{1}{6}\\)

Ejemplo 3: Fracción por número entero

Calcular: \\(\\frac{3}{7} \\times 4\\)

Convertimos el entero a fracción: \\(4 = \\frac{4}{1}\\)

\\[ \\frac{3}{7} \\times 4 = \\frac{3}{7} \\times \\frac{4}{1} = \\frac{3 \\times 4}{7 \\times 1} = \\frac{12}{7} = 1\\frac{5}{7} \\]

División de Fracciones

Para dividir fracciones, multiplicamos la primera fracción por el inverso (recíproco) de la segunda fracción.

Regla de división

\\[ \\frac{a}{b} \\div \\frac{c}{d} = \\frac{a}{b} \\times \\frac{d}{c} = \\frac{a \\times d}{b \\times c} \\quad \\text{con } b \\neq 0, c \\neq 0, d \\neq 0 \\]

💡 Consejo

El recíproco de \\(\\frac{c}{d}\\) es \\(\\frac{d}{c}\\). Es como "dar la vuelta" a la fracción.

Ejemplo 1: División básica

Calcular: \\(\\frac{2}{3} \\div \\frac{4}{5}\\)

Paso 1: Multiplicar por el recíproco: \\(\\frac{2}{3} \\times \\frac{5}{4}\\)

Paso 2: Simplificar y calcular: \\(\\frac{2 \\times 5}{3 \\times 4} = \\frac{10}{12} = \\frac{5}{6}\\)

Resultado: \\(\\frac{2}{3} \\div \\frac{4}{5} = \\frac{5}{6}\\)

Ejemplo 2: División por un entero

Calcular: \\(\\frac{3}{4} \\div 2\\)

Convertimos el entero a fracción: \\(2 = \\frac{2}{1}\\), y aplicamos la regla

\\[ \\frac{3}{4} \\div 2 = \\frac{3}{4} \\div \\frac{2}{1} = \\frac{3}{4} \\times \\frac{1}{2} = \\frac{3}{8} \\]

Ejemplo 3: División con simplificación

Calcular: \\(\\frac{6}{15} \\div \\frac{3}{10}\\)

\\[ \\frac{6}{15} \\div \\frac{3}{10} = \\frac{6}{15} \\times \\frac{10}{3} = \\frac{6 \\times 10}{15 \\times 3} \\]

Simplificamos antes de calcular:

\\[ = \\frac{\\cancel{6}}{\\cancel{15}} \\times \\frac{\\cancel{10}}{\\cancel{3}} = \\frac{2}{5} \\times \\frac{2}{1} = \\frac{4}{5} \\]

Resultado: \\(\\frac{6}{15} \\div \\frac{3}{10} = \\frac{4}{5}\\)

Errores Típicos

  • ERROR: \\(\\frac{a}{b} + \\frac{c}{d} = \\frac{a+c}{b+d}\\)
    CORRECTO: \\(\\frac{a}{b} + \\frac{c}{d} = \\frac{a \\cdot d + c \\cdot b}{b \\cdot d}\\)
  • ERROR: Sumar denominadores al buscar denominador común
    CORRECTO: Calcular el mcm de los denominadores
  • ERROR: Cambiar solo uno de los términos al restar fracciones
    CORRECTO: Cambiar el signo a todo el término que se mueve
  • ERROR: Dividir fracciones multiplicando numeradores y denominadores directamente
    CORRECTO: Multiplicar por el recíproco de la segunda fracción
