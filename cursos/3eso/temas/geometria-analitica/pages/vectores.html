Vectores

¿Qué es un Vector?

Un vector es un segmento dirigido que tiene magnitud, dirección y sentido. Se utiliza para representar magnitudes que tienen estas tres características, como la velocidad, la fuerza o el desplazamiento.

Magnitud: Longitud del vector

Dirección: Recta sobre la que actúa

Sentido: Hacia dónde apunta

Componentes de un Vector

Un vector puede expresarse mediante sus componentes en un sistema de coordenadas cartesianas. Si tenemos un vector que va desde el punto A(x₁, y₁) hasta el punto B(x₂, y₂):

Componentes del vector:

\\[ \\vec{AB} = (x_2 - x_1, y_2 - y_1) \\]

Ejemplo: Halla las componentes del vector que va de P(2, 3) a Q(7, 8)

Solución:

\\[ \\vec{PQ} = (7 - 2, 8 - 3) = (5, 5) \\]

Operaciones con Vectores

Suma de Vectores

Para sumar dos vectores, sumamos sus componentes correspondientes:

\\[ (a, b) + (c, d) = (a+c, b+d) \\]

Producto por un Escalar

Para multiplicar un vector por un número (escalar), multiplicamos cada componente por ese número:

\\[ k \\cdot (a, b) = (ka, kb) \\]

Ejemplo de operaciones:

Dados los vectores u = (3, 4) y v = (1, 2)

1. \\[ \\vec{u} + \\vec{v} = (3, 4) + (1, 2) = (4, 6) \\]

2. \\[ 2 \\cdot \\vec{u} = 2 \\cdot (3, 4) = (6, 8) \\]

3. \\[ 3\\vec{u} - 2\\vec{v} = 3(3, 4) - 2(1, 2) = (9, 12) - (2, 4) = (7, 8) \\]

Módulo de un Vector

El módulo (o longitud) de un vector es la distancia desde su origen hasta su extremo. Se calcula aplicando el teorema de Pitágoras a sus componentes:

Fórmula del módulo:

\\[ |\\vec{v}| = \\sqrt{a^2 + b^2} \\]

Ejemplo: Calcula el módulo del vector w = (6, 8)

Solución:

\\[ |\\vec{w}| = \\sqrt{6^2 + 8^2} = \\sqrt{36 + 64} = \\sqrt{100} = 10 \\]

Vectores Especiales

Vector Nulo

Es el vector (0, 0). No tiene dirección ni sentido definidos.

Vector Unitario

Es un vector cuyo módulo es 1. Se obtiene dividiendo un vector por su módulo.

\\[ \\hat{v} = \\frac{\\vec{v}}{|\\vec{v}|} \\]

Vectores Ouestos

Dos vectores son opuestos si tienen la misma magnitud y dirección, pero sentido contrario.

\\[ \\vec{v} = (a, b) \\quad \\text{vs} \\quad -\\vec{v} = (-a, -b) \\]

⚠️ Errores Típicos

  • Orden inverso en las componentes: Calcular (x₁ - x₂, y₁ - y₂) en lugar de (x₂ - x₁, y₂ - y₁)
  • Confundir módulo con componentes: Pensar que el módulo es (a, b) en lugar de √(a² + b²)
  • Error en la suma: Restar en lugar de sumar las componentes
  • Confundir vector con punto: Un vector es (x, y) pero no es lo mismo que el punto (x, y)
