Características de las Funciones

Dominio de una Función

El dominio es el conjunto de todos los valores que puede tomar la variable independiente x para que la función esté bien definida.

Casos especiales según el tipo de función:

  • Función polinómica: Dom = ℝ (todos los números reales)
  • Función racional: No puede haber división por 0
  • Función radical: El radicando debe ser ≥ 0 (si es raíz par)

Recorrido o Rango

El recorrido es el conjunto de todos los valores que toma la función. Se obtiene observando todos los posibles resultados de f(x).

Ejemplo: Para f(x) = x², el dominio es ℝ pero el recorrido es [0, +∞)

Continuidad

Una función es continua si podemos dibujarla sin levantar el lápiz del papel. No debe tener "saltos" o "huecos".

Tipos de discontinuidad:

  • Discontinuidad de salto: La función "salta" de un valor a otro
  • Discontinuidad infinita: La función "se va al infinito"
  • Discontinuidad evitable: Hay un "hueco" en la gráfica

Monotonía (Crecimiento y Decrecimiento)

Función Creciente:

Si x₁ < x₂ entonces f(x₁) < f(x₂). A medida que x aumenta, f(x) también aumenta.

Función Decreciente:

Si x₁ < x₂ entonces f(x₁) > f(x₂). A medida que x aumenta, f(x) disminuye.

Función Constante:

f(x₁) = f(x₂) para cualquier x₁ y x₂. El valor no cambia.

Extremos Relativos

Máximo Relativo:

Un punto a es un máximo relativo si f(a) ≥ f(x) para todo x cercano a a.

Mínimo Relativo:

Un punto a es un mínimo relativo si f(a) ≤ f(x) para todo x cercano a a.

Ejemplos Visuales

f(x) = 2x + 1 es una función creciente en todo su dominio.

x f(x) = 2x + 1
-2 -3
-1 -1
0 1
1 3

Observa: cuando x aumenta, f(x) también aumenta

f(x) = -x + 3 es una función decreciente en todo su dominio.

x f(x) = -x + 3
0 3
1 2
2 1
3 0

Observa: cuando x aumenta, f(x) disminuye

f(x) = -x² + 4 tiene un máximo en el punto (0, 4).

x f(x) = -x² + 4
-2 0
-1 3
0 4
1 3
2 0

El máximo está marcado en color

⚠️ Errores Típicos

  • Confundir dominio con recorrido
  • No identificar correctamente los intervalos de crecimiento
  • Confundir extremos relativos con absolutos
  • No considerar todas las restricciones del dominio
