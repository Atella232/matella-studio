Concepto de Función

¿Qué es una Función?

Una función es como una máquina matemática que toma un valor de entrada (input) y produce un único valor de salida (output). Cada vez que introduces el mismo valor de entrada, siempre obtendrás el mismo resultado.

Definición formal: Una función f es una relación que asigna a cada elemento x de un conjunto dominio un único elemento y de un conjunto recorrido.

Notación de Funciones

Las funciones se escriben como f(x) y se leen "f de x". Esto significa que la función f se aplica al valor x.

Notación general:

y = f(x)

donde:

  • x es la variable independiente
  • y es la variable dependiente

Dominio y Recorrido

Toda función tiene dos conjuntos importantes:

Dominio (Dom):

Conjunto de todos los valores que puede tomar la variable independiente x. Es el conjunto de entrada.

Recorrido o Rango (Im):

Conjunto de todos los valores que toma la función. Es el conjunto de salida.

Representaciones de una Función

Se expresa mediante una fórmula matemática que relaciona x con y.

Ejemplos: f(x) = 2x + 1, g(x) = x², h(x) = 1/x

Se dibuja en un sistema de coordenadas. El eje X representa la variable independiente y el eje Y la variable dependiente.

Prueba: Si trazamos f(x) = 2x + 1, obtenemos una línea recta

Se presenta en forma de tabla con valores de x y sus correspondientes f(x).

Ejemplo Práctico

Imagina que f(x) = 2x + 1 representa el coste de comprar x entradas de cine a 2€ cada una, más 1€ de gastos de reserva.

Calculemos algunos valores:

  • Si compras 0 entradas: f(0) = 2(0) + 1 = 1€ (solo gastos de reserva)
  • Si compras 3 entradas: f(3) = 2(3) + 1 = 7€
  • Si compras 10 entradas: f(10) = 2(10) + 1 = 21€

⚠️ Errores Típicos

  • Confundir función con relación general: No todas las relaciones son funciones
  • No verificar la unicidad: Cada x debe tener UN solo f(x)
  • Confundir dominio con recorrido
