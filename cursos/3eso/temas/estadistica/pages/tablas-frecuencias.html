Tablas de Frecuencias

¿Qué es una Tabla de Frecuencias?

Una tabla de frecuencias es una herramienta que organiza los datos de una variable estadística, mostrando cuántas veces aparece cada valor (frecuencia) y otras medidas relacionadas. Facilita el análisis y la interpretación de los datos.

Tipos de Frecuencias

Frecuencia Absoluta (fᵢ)

Número de veces que aparece cada valor en la población o muestra. Es un número entero que indica la repetición de un dato específico.

Fórmula: fᵢ = número de veces que aparece el valor i

Frecuencia Relativa (hᵢ)

Proporción que representa cada frecuencia absoluta respecto al total. Se expresa como fracción decimal o porcentaje.

Fórmula: \\[ h_i = \frac{f_i}{N} \\] donde N es el total de datos

Frecuencia Absoluta Acumulada (Fᵢ)

Suma de todas las frecuencias absolutas hasta ese valor. Indica cuántos datos son menores o iguales a un valor determinado.

Fórmula: \\[ F_i = f_1 + f_2 + \dots + f_i \\]

Frecuencia Relativa Acumulada (Hᵢ)

Suma de todas las frecuencias relativas hasta ese valor. Se expresa como proporción del total.

Fórmula: \\[ H_i = h_1 + h_2 + \dots + h_i \\]

Ejemplo Completo

Supongamos que preguntamos a 20 estudiantes por su número de hermanos. Los datos obtenidos son:

2, 1, 0, 3, 1, 2, 1, 4, 0, 1, 2, 1, 3, 1, 0, 2, 1, 1, 2, 3

Propiedades de las Frecuencias

Suma de Frecuencias Absolutas

\\[ \sum f_i = N \\]

La suma de todas las frecuencias absolutas debe ser igual al número total de datos.

Suma de Frecuencias Relativas

\\[ \sum h_i = 1 \\]

La suma de todas las frecuencias relativas debe ser igual a 1 (o 100%).

Suma de Frecuencias Acumuladas

\\[ \sum H_i = 1 \\]

La suma de las frecuencias relativas acumuladas debe ser igual a 1.

Representaciones Gráficas

Se utiliza para variables cualitativas y cuantitativas discretas. Cada valor se representa con una barra cuya altura es proporcional a su frecuencia.

Uso: Mostrar la distribución de calificaciones, número de hermanos, tipo de sangre.

Se utiliza principalmente para variables cualitativas. Cada categoría ocupa un sector proporcional a su frecuencia relativa.

Uso: Mostrar la distribución de colores de ojos, estado civil, preferencias deportivas.

Se utiliza para variables cuantitativas continuas o datos agrupados en intervalos. Las barras están unidas y representan la frecuencia de cada intervalo.

Uso: Mostrar la distribución de alturas, pesos, calificaciones agrupadas.

Se obtiene uniendo los puntos medios de las barras de un diagrama de barras o histograma. Es útil para comparar distribuciones.

Uso: Analizar tendencias en datos temporales, comparar grupos.

Errores Típicos

  • No verificar que la suma de frecuencias absolutas sea igual al total: Siempre comprobar que ∑fᵢ = N
  • Confundir frecuencia absoluta con relativa: La absoluta es un conteo, la relativa es una proporción
  • No comprobar que la suma de frecuencias relativas sea 1: Error común que indica mistake en los cálculos
