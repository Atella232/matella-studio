Ecuaciones de Segundo Grado

¿Qué es una Ecuación de Segundo Grado?

Una ecuación de segundo grado es una igualdad matemática que contiene una incógnita elevada a la potencia 2. También se conoce como ecuación cuadrática.

Forma General

\[ax^2 + bx + c = 0 \quad \text{donde} \quad a \neq 0\]

Donde a, b y c son números conocidos (coeficientes) y a ≠ 0 (si a = 0, sería una ecuación de primer grado).

Fórmula Cuadrática

Esta es la fórmula más importante para resolver ecuaciones de segundo grado:

\[x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\]

Recordatorio: El símbolo ± significa que existen dos soluciones: una con + y otra con -

El Discriminante

La parte bajo la raíz cuadrada se llama discriminante y nos indica cuántas soluciones reales tiene la ecuación:

\[\Delta = b^2 - 4ac\]

La ecuación tiene dos soluciones reales distintas.

Ejemplo: x² - 5x + 6 = 0 → Δ = (-5)² - 4(1)(6) = 25 - 24 = 1 > 0

La ecuación tiene una sola solución real (solución doble).

Ejemplo: x² - 4x + 4 = 0 → Δ = (-4)² - 4(1)(4) = 16 - 16 = 0

La ecuación no tiene soluciones reales (las soluciones son números complejos).

Ejemplo: x² + x + 1 = 0 → Δ = 1² - 4(1)(1) = 1 - 4 = -3 < 0

Casos Especiales

Algunas ecuaciones de segundo grado pueden resolverse de forma más sencilla sin usar la fórmula general.

\[ax^2 + c = 0\]

Pasos para resolver:

\\[ax^2 = -c\\]

\\[x^2 = -\frac{c}{a}\\]

\\[x = \pm\sqrt{-\frac{c}{a}}\\]

Ejemplo: 2x² - 8 = 0 → 2x² = 8 → x² = 4 → x = ±2

\[ax^2 + bx = 0\]

Factor común y aplicación de la regla del producto nulo:

\\[x(ax + b) = 0\\]

\\[x = 0 \quad \text{o} \quad ax + b = 0\\]

\\[x = 0 \quad \text{o} \quad x = -\frac{b}{a}\\]

Ejemplo: x² - 3x = 0 → x(x - 3) = 0 → x = 0 o x = 3

Ejemplo Completo con Fórmula General

Vamos a resolver la ecuación: \\(x^2 - 5x + 6 = 0\\)

Identificar coeficientes:

\\[a = 1, \\quad b = -5, \\quad c = 6\\]

Calcular el discriminante:

\\[\Delta = b^2 - 4ac = (-5)^2 - 4(1)(6) = 25 - 24 = 1\\]

Como Δ = 1 > 0, la ecuación tiene dos soluciones reales.

Aplicar la fórmula cuadrática:

\\[x = \\frac{-(-5) \\pm \\sqrt{1}}{2(1)} = \\frac{5 \\pm 1}{2}\\]

Calcular las dos soluciones:

\\[x_1 = \\frac{5 + 1}{2} = \\frac{6}{2} = 3\\]

\\[x_2 = \\frac{5 - 1}{2} = \\frac{4}{2} = 2\\]

Solución: x = 2 o x = 3
Comprobación: Para x = 2: 2² - 5(2) + 6 = 4 - 10 + 6 = 0 ✓
Para x = 3: 3² - 5(3) + 6 = 9 - 15 + 6 = 0 ✓

Ejemplo con Ecuación Incompleta

Resolver: \\(2x^2 - 8 = 0\\)

Como c = 0:

\\[2x^2 = 8\\]

\\[x^2 = 4\\]

\\[x = \\pm\\sqrt{4} = \\pm2\\]

Solución: x = 2 o x = -2

⚠️ Errores Típicos

  • Olvidar el signo ±: Escribir solo \\(x = \\frac{-b + \\sqrt{b^2 - 4ac}}{2a}\\) y olvidar la solución con -
  • Error en el cálculo del discriminante: Confundir los signos de b, c o calcular mal b²
  • No comprobar las soluciones: Siempre debemos verificar sustituyendo en la ecuación original
  • Confundir a, b, c: Recordar que van en el orden de los términos: ax² + bx + c

Aplicaciones Prácticas

Las ecuaciones de segundo grado aparecen en muchos problemas de geometría, física y ciencias.

Problema de área:

Un rectángulo tiene 6 metros más de largo que de ancho. Si su área es 55 m², ¿cuáles son sus dimensiones?

Planteamiento:

\\[x = \\text{ancho (m)}\\]

\\[x + 6 = \\text{largo (m)}\\]

\\[x(x + 6) = 55\\]

Resolución:

\\[x^2 + 6x - 55 = 0\\]

\\[a = 1, \\quad b = 6, \\quad c = -55\\]

\\[\Delta = 6^2 - 4(1)(-55) = 36 + 220 = 256\\]

\\[x = \\frac{-6 \\pm \\sqrt{256}}{2} = \\frac{-6 \\pm 16}{2}\\]

Solución:

\\[x = \\frac{-6 + 16}{2} = 5, \\quad x = \\frac{-6 - 16}{2} = -11\\]

Como las dimensiones no pueden ser negativas, el ancho es 5 m y el largo es 11 m.
