Igualdades con Incógnitas

Las ecuaciones son igualdades matemáticas que contienen una o más incógnitas (valores desconocidos). El objetivo es encontrar el valor de estas incógnitas que hacen que la igualdad sea cierta.

Ejemplo:

  • 2x + 3 = 7, entonces x = 2
  • x² - 5x + 6 = 0, entonces x = 2 o x = 3
  • x⁴ - 5x² + 6 = 0, entonces x = ±√2 o x = ±√3
  • Resolver = encontrar el valor desconocido

Contenidos del Tema

Ecuaciones de Primer Grado

Ecuaciones lineales simples
• Forma: ax + b = c
• Método: Operaciones inversas para aislar x
• Propiedades: Sumar, restar, multiplicar o dividir
• Verificación: Sustituir la solución en la ecuación original

Ecuaciones de Segundo Grado

Ecuaciones cuadráticas
• Forma: ax² + bx + c = 0
• Fórmula: x = (-b ± √(b²-4ac)) / 2a
• Casos: Incompletas (b=0 o c=0) y completas
• Soluciones: Pueden tener 2, 1 o 0 soluciones reales

Ecuaciones Bicuadradas

Ecuaciones de cuarto grado especiales
• Forma: ax⁴ + bx² + c = 0
• Sustitución: y = x², convierte a ecuación de 2º grado
• Solución: Encontrar y, luego x = ±√y
• Casos: Dependiendo del discriminante de la ecuación en y
