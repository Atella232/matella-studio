Conjuntos de Ecuaciones

Un sistema de ecuaciones es un conjunto de dos o más ecuaciones con las mismas variables que se deben cumplir simultáneamente. La solución es el conjunto de valores que satisface todas las ecuaciones a la vez.

Ejemplo:

  • 2x + y = 7
  • x - y = 1
  • Solución: x = 3, y = 1

Contenidos del Tema

Método de Sustitución

Sustituir una variable por su expresión
• Concepto: Despejar una variable y sustituir
• Pasos: Despejar → Sustituir → Resolver → Comprobar
• Ventajas: Bueno para ecuaciones lineales simples
• Errores comunes: Errores en la sustitución

Método de Eliminación

Eliminar una variable sumando/restas ecuaciones
• Concepto: Multiplicar y sumar/restar para eliminar
• Pasos: Igualar coeficientes → Sumar/restar → Resolver
• Ventajas: Rápido y sistemático
• Errores comunes: Error al multiplicar por el mismo número

Método Gráfico

Representar las rectas e intersectar
• Concepto: Dibujar las rectas y encontrar intersección
• Pasos: Despejar y → Dibujar rectas → Marcar punto
• Ventajas: Visual y comprensible
• Errores comunes: Escalas incorrectas en los ejes
