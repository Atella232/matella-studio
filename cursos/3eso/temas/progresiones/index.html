Secuencias con Patrón

Las progresiones son secuencias de números que siguen una regla fija. Cada término se obtiene a partir del anterior mediante una operación específica. Son la base para entender patrones matemáticos y modelar situaciones que cambian de forma predecible.

Ejemplo:

  • 2, 4, 6, 8, 10... (diferencia +2)
  • 3, 6, 12, 24, 48... (razón ×2)

Contenidos del Tema

Progresiones Aritméticas

Suma constante entre términos
• Concepto: Secuencia donde cada término se obtiene sumando una diferencia constante
• Fórmula: aₙ = a₁ + (n-1)d
• Término general: Encontrar cualquier término de la progresión
• Aplicaciones: Crecimiento lineal, edades, pagos fijos

Progresiones Geométricas

Multiplicación constante entre términos
• Concepto: Secuencia donde cada término se obtiene multiplicando por una razón constante
• Fórmula: aₙ = a₁ × rⁿ⁻¹
• Razón: Cociente entre términos consecutivos
• Aplicaciones: Crecimiento exponencial, interés compuesto, poblaciones

Sumas de Progresiones

Sumando todos los términos
• Aritmética: Sₙ = n(a₁ + aₙ)/2
• Geométrica: Sₙ = a₁(rⁿ-1)/(r-1) o S∞ = a₁/(1-r)
• Suma infinita: Solo convergente si |r| < 1
• Aplicaciones: Cálculo de totales, series infinitas, física
