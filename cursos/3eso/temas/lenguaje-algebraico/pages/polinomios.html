Polinomios

¿Qué es un Polinomio?

Un polinomio es una expresión algebraica formada por la suma o resta de varios monomios (cuatro o más).

Ejemplo: $P(x) = 3x^3 + 2x^2 - 5x + 7$ es un polinomio de grado 3 en la variable x.

Valor Numérico de un Polinomio

El valor numérico de un polinomio es el resultado que obtenemos al sustituir las variables por valores numéricos concretos.

Proceso:
1. Sustituir cada variable por su valor
2. Realizar las operaciones respetando el orden
3. Simplificar el resultado

Ejemplo: Dado $P(x) = x^2 + 3x - 4$, calcular $P(2)$:

$P(2) = (2)^2 + 3(2) - 4$
$P(2) = 4 + 6 - 4$
$P(2) = 6$

Otro ejemplo: Dado $Q(a,b) = 2a + 3ab - b^2$, calcular $Q(1,3)$:

$Q(1,3) = 2(1) + 3(1)(3) - (3)^2$
$Q(1,3) = 2 + 9 - 9$
$Q(1,3) = 2$

Suma de Polinomios

Para sumar polinomios, agrupamos los términos semejantes y sumamos sus coeficientes.

Regla: $(a_1x^n + ... + a_0) + (b_1x^n + ... + b_0) = (a_1+b_1)x^n + ... + (a_0+b_0)$

Ejemplo:
$P(x) = 2x^3 + 3x^2 - x + 5$
$Q(x) = x^3 - 2x^2 + 4x - 3$

$P(x) + Q(x) = (2x^3 + x^3) + (3x^2 - 2x^2) + (-x + 4x) + (5 - 3)$
$P(x) + Q(x) = 3x^3 + x^2 + 3x + 2$

Resta de Polinomios

Para restar polinomios, cambiamos los signos de todos los términos del segundo polinomio y luego sumamos.

Proceso: $P(x) - Q(x) = P(x) + (-Q(x))$

Ejemplo:
$P(x) = 3x^3 + 2x^2 - x + 1$
$Q(x) = x^3 - 5x^2 + 3x + 2$

$P(x) - Q(x) = (3x^3 + 2x^2 - x + 1) - (x^3 - 5x^2 + 3x + 2)$
$P(x) - Q(x) = 3x^3 + 2x^2 - x + 1 - x^3 + 5x^2 - 3x - 2$
$P(x) - Q(x) = (3x^3 - x^3) + (2x^2 + 5x^2) + (-x - 3x) + (1 - 2)$
$P(x) - Q(x) = 2x^3 + 7x^2 - 4x - 1$

Multiplicación de Polinomios

Para multiplicar polinomios, aplicamos la propiedad distributiva: cada término del primer polinomio se multiplica por cada término del segundo polinomio.

Ejemplo:
$P(x) = 2x + 3$
$Q(x) = x - 1$

$P(x) \cdot Q(x) = (2x + 3)(x - 1)$
$= 2x \cdot x + 2x \cdot (-1) + 3 \cdot x + 3 \cdot (-1)$
$= 2x^2 - 2x + 3x - 3$
$= 2x^2 + x - 3$

Pasos:
1. Multiplicar cada término del primer polinomio por cada término del segundo
2. Sumar todos los productos obtenidos
3. Simplificar sumando términos semejantes

Ejemplo:
$P(x) = x^2 + 2x - 1$
$Q(x) = x + 3$

$(x^2 + 2x - 1)(x + 3)$

$= x^2(x + 3) + 2x(x + 3) - 1(x + 3)$
$= x^3 + 3x^2 + 2x^2 + 6x - x - 3$
$= x^3 + (3x^2 + 2x^2) + (6x - x) - 3$
$= x^3 + 5x^2 + 5x - 3$

División de Polinomios (por Monomios)

En 3º ESO, la división de polinomios se limita a dividir un polinomio por un monomio.

Proceso: Dividir cada término del polinomio por el monomio

Ejemplo:
$(6x^3 + 9x^2 - 3x) \div 3x$

$= \frac{6x^3}{3x} + \frac{9x^2}{3x} + \frac{-3x}{3x}$
$= 2x^2 + 3x - 1$

Verificación: $2x^2 + 3x - 1$ multiplicado por $3x$ debe dar $6x^3 + 9x^2 - 3x$

Propiedades Importantes

El grado del producto de dos polinomios es la suma de los grados.

Ejemplo: grad$(x^2 + 1)$ = 2, grad$(x^3 - 2x)$ = 3, entonces grad$[(x^2 + 1)(x^3 - 2x)]$ = 2 + 3 = 5

El grado de la suma o resta de dos polinomios es menor o igual que el mayor de los grados.

Ejemplo: $(x^3 + 2x^2) + (x^2 + 1) = x^3 + 3x^2 + 1$ (grado 3 = max(3,2))

Errores Típicos

  • No cambiar signos al restar polinomios: ❌ $(x^2 + 3x) - (2x - 1) = x^2 + 3x - 2x - 1$ (incorrecto) ✓ $x^2 + 3x - 2x + 1$ (correcto)
  • Olvidar términos al multiplicar: No multiplicar todos los términos entre sí
  • No simplificar el resultado final: Dejar términos semejantes sin agrupar
  • Confundir el grado del producto: No sumar los grados de los factores
