First 1. DBH unit rebuilt on the V2 engine (owner wants all DBH1 units at the level of the DBH2 ones; see [[v2-redesign-direction]]). Branch `feat/zenbaki-naturalak-dbh1`, route `matematika/dbh1/zenbaki-naturalak/*`, code in `src/pages/dbh1-zenbaki-naturalak-v2/` (legacy `dbh1-zenbaki-naturalak/` left on disk, unrouted — delete once V2 is approved).

Sources: class follows **Santillana 1.º ESO unit 1** (owner gave the "adaptación curricular" PDF: decimal system, operations, combined, calculator, powers incl. base 10) plus **Anaya unit 1** solutions (Egyptian/Roman systems, large numbers, rounding, properties, problems). Also the Basque class guide `cursos/1eso/temas/numeros-naturales/Zenbaki Arruntak eta Hamartarrak_ 1.pdf`: jumps on the number line, rounding rule, "semaforoa" (red brackets, yellow ·:, green +−) and D-P-E problem structure (Datuak, Prozedura, Erantzuna). Decimals (hamartarrak) are a SEPARATE later unit (owner).

Scope chosen: 14 lessons, 5 stages — numbering (place value, big numbers, order/number line, Roman), rounding (rounding, estimation), operations (+−, × properties, ÷ with D = d·c + r), combined (hierarchy, brackets/kako zuzenak, D-P-E problems), powers (powers, powers of 10). Calculator lesson skipped. Large numbers written with a point (15.728) as in class — phase 2 answer parsing must NOT read "15.000" as a decimal.

Phases: 1) lessons + route [done 2026-09-27, commit 7a9dff3]; 2) diagnostic 8, practice 19, bank 30, challenges 12 [done 2026-09-27, `content.ts`; engine got `answers.normalizeInput`, unit uses `readNaturalAnswer` in `numbers.ts` (also toRoman/fromRoman); tests in `tests/zenbaki-naturalak-content.test.ts` evaluate every worked equality]; 3) lab [done 2026-09-27: 8 tools × 4 challenges in `lab/` (abacus, line, roman, rounding, distributive, division, semaphore, powers); step-by-step expression logic now shared in `src/features/unit-v2/math/expression.ts` and NumberField in `src/features/unit-v2/lab/NumberField.tsx` (also used by DBH2 units); tests `tests/zenbaki-naturalak-lab.test.ts`]; 4) games [done 2026-09-27: race 5 circuits, hunt, semaphore sprint, memory in `games/`; tests `tests/zenbaki-naturalak-games.test.ts`]. All four phases merged to main (fast-forward, f479cd9), pushed and deployed to matella.net on 2026-09-27 at the owner's request. Legacy folder deleted 2026-09-27 at the owner's request. Gotcha: node --test cannot import .tsx, keep lab logic in .ts files.
