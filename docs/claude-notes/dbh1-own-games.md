# 1. DBH own games

On 2026-11-02, after the 2. DBH and 4. DBH own games, the owner said «Sí, hazlo así»: give every 1. DBH unit at least two own games (beyond race, memory and games borrowed from 2. DBH) plus a detective of its typical mistakes, all in a row, then ask before publishing. Labs already had 5–9 own tools each, so only games are built.

Rules kept from 4. DBH: predict first and draw after answering; steppers never start on the answer; detective lines short (≤ ~232 px at 21 px). Code lives in each unit's `games/` folder (`OwnGames.tsx`, a logic `.ts`, `detective.ts`, `OwnGames.css`), so the inventory counts it as own. Engine pieces reused: `RoundGame`, `RoundVerdict`, `Stepper`, `WorkedDetectiveGame`, `DetectiveArt`, `standardStars`. Tests in `tests/dbh1-own-games.test.ts`; the detective helpers (`checkDetective`, `checkLanguages`, `endValue`) moved to `tests/helpers/ownGamesCheck.ts`.
