The owner chose direction "D · Cuaderno a color" from the design canvas https://claude.ai/artifact/S4XSWD1dnLBvr4uyewSbbd (the base "A · Cuaderno" plus the color of "B · Taller").

Key traits: paper background #F6F1E7, cards #FFFCF6, ink #1D2733, muted #58616E; Fraunces for headings, Atkinson Hyperlegible for body; five stage colors (blue #2F6FDB, violet #7A55D6, mustard #E0A100, coral #D9502E, green #267B53) each with a light tint; 1.5–2px ink borders and solid offset shadows only on key elements (primary button, current stage, lesson card, key idea); graph-paper backgrounds behind math models; light theme first.

**Why:** owner found the V2 dark/glass look generic; liked A's calm, editorial feel but wanted B's color and energy.

**How to apply:** use this as the design system for V2 and for every unit later extended from it (see [[v2-redesign-direction]]). Check text contrast on stage colors (white text needs the darker variants).
